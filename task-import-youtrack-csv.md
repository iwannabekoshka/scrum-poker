# Импорт задач из .csv

В списке задач нужно добавить кнопку "Импортировать YouTrack .csv", по нажатию на которую показывается окно выбора .csv файла, и после выбора файла список задач заменяется на загруженный.

Требования:
- Добавить кнопку "Импортировать YouTrack .csv" в списке задач.
- По нажатию открывается окно выбора .csv файла.
- При импорте берутся поля: "Summary" - название задачи, "Issue Id" - с помощью этого поля формируется ссылка на задачу, формула: "https://pvs-studio.myjetbrains.com/youtrack/issue/id-16066" + "Issue Id"
- При импорте текущий список задач заменяется на загруженный.
- Если в .csv нет нужных полей - показывается ошибка "Данный .csv файл не соответствует формату".
- Рядом с кнопкой импорта есть значок info, по клику на которую открывается новое окно со страницей /how-to-export-youtrack-tasks/, где пока что будет текст-заглушка.

Пример .csv файла можно посмотреть в issues-example.csv.
