# Scrum Poker

Веб‑приложение для проведения планирования в формате Planning Poker. Позволяет распределённым командам быстро собирать комнату, добавлять задачи и синхронно голосовать за их оценку, используя карты Фибоначчи и специальные значения.

## Возможности
- Создание комнаты «на лету»: достаточно ввести ID, чтобы комната появилась на сервере.
- Подключение участников по имени с отображением статуса подключения и выделением текущего пользователя.
- Голосование картами (0–100, ?, ☕), автоматическое определение, что все участники сделали выбор.
- Управление раундами: показ/скрытие результатов, сброс голосов, фиксация текущей задачи.
- Авторасчёт времени на задачу после голосования (среднее значение карт) и ручное редактирование оценки в сайдбаре.
- Боковая панель задач: добавление, удаление, выбор текущей задачи, хранение ссылок на YouTrack.
- Синхронизация состояния в реальном времени через WebSocket (Socket.IO).

## Архитектура
- `backend/` — сервер на Express + Socket.IO. Отвечает за управление комнатами, хранение пользователей и задач в памяти, трансляцию событий и отдачу статического билда фронтенда.
- `frontend/` — React‑клиент. Содержит экран входа, игровое поле с карточками, список участников и панель задач. Общается с сервером по WebSocket через кастомный хук `useSocket`.

## Быстрый старт (локально)
1. Запустите сервер:
   ```bash
   cd backend
   npm install
   npm run dev
   ```
   По умолчанию сервер слушает порт `5000` и выставляет WebSocket для клиентов.
2. Запустите фронтенд:
   ```bash
   cd frontend
   npm install
   npm start
   ```
   React‑приложение откроется на `http://localhost:3000` и будет подключаться к бекенду.

> Для production‑сборки выполните `npm run build` во фронтенде — статические файлы автоматически обслуживаются Express‑сервером из `frontend/build`.

## Типичный сценарий
1. Участники выбирают общий `roomId` и вводят его вместе со своим именем на экране входа. Если комнаты не существовало, сервер создаст её автоматически.
2. Ведущий добавляет задачи в сайдбар: можно указать название и URL тикета YouTrack.
3. При выборе задачи у всех пользователей отображается её название, сбрасываются предыдущие голоса.
4. Каждый участник выбирает карту. Как только все проголосовали, появляется возможность открыть результаты.
5. После обсуждения ведущий может начать новый раунд или перейти к следующей задаче.

## Технологии
- **Backend:** Node.js, Express, Socket.IO, ES Modules.
- **Frontend:** React 18, socket.io-client, React Scripts.
